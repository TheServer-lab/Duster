# Fly Legal Notes

## This document is explanatory

This file is intended to explain the licensing position of the Fly project in plain language.

It is **not a replacement for the project's actual license** and does not grant additional rights.

The `LICENSE` file is the authoritative source for the legal terms governing Fly.

---

## Fly is licensed under PolyForm Noncommercial

Fly's source code is licensed under the:

**PolyForm Noncommercial License 1.0.0**

The license permits the uses described in its terms, including permitted noncommercial use.

Commercial use is not granted by the PolyForm Noncommercial License.

---

## Do not misrepresent Fly as commercially licensed

Fly may be copied, modified, forked, or redistributed only according to the actual license that applies to the relevant code.

In particular, do not:

* claim that Fly is MIT-licensed when it is not;
* remove or replace Fly's actual license while representing the resulting code as officially licensed by Fly;
* reinterpret a noncommercial license as permission for commercial use;
* distribute a modified version as though the original Fly project granted commercial rights when it did not;
* use a third-party license file to create the impression that Fly itself is commercially licensed.

The project considers attempts to **"license-launder"** Fly—such as taking code governed by PolyForm Noncommercial and presenting it as though it were commercially permitted—to be a misrepresentation of the project's licensing terms.

---

## About MIT-licensed code

MIT-licensed code is legally different from PolyForm Noncommercial-licensed code.

The MIT License generally grants broad rights, including commercial use.

Therefore, a project cannot make MIT-licensed code noncommercial merely by placing a document such as this one next to it.

If a specific file or component in the Fly repository is genuinely licensed under MIT, that license governs that component according to its own terms.

If there is any conflict between this explanatory document and an actual license file, **the actual applicable license controls**.

---

## Third-party code

Fly may contain dependencies, libraries, or other components with licenses different from Fly's own license.

Those components remain subject to their respective licenses.

Do not assume that Fly's license automatically applies to third-party software.

---

## Commercial use

Anyone intending to use Fly commercially should first determine whether the intended use is permitted by the applicable license.

If the use is not permitted, obtain the necessary separate permission or commercial license from the copyright holder before proceeding.

Do not assume that compiling Fly, forking Fly, embedding Fly, or distributing software built with Fly automatically grants commercial rights to the Fly source code.
